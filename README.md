# ☕ Velvet Brew – Coffee Shop Website

Velvet Brew is a fully responsive multi-page coffee shop website built using HTML, CSS, Bootstrap, and JavaScript.  
It represents a luxury café brand with elegant design, smooth animations, and interactive features.

---

## 🚀 Live Preview
[VelVet Brew Coffee Shop ](https://kashish706.github.io/VelVetBrew_CoffeeShop/)

---

## 🌟 Live Features

- Responsive design (Mobile + Tablet + Desktop)
- Sticky & hide-on-scroll navbar
- Animated hero section
- Menu filter functionality
- Order form with auto price calculation
- Contact form with success message
- Gallery with hover zoom effect
- Animated statistics counter
- Premium velvet-themed UI

## 🚀 How to Run

1. Download or Clone the repository
2. Open project folder
3. Run `index.html` using Live Server or browser

---

## 🌐 Deployment (GitHub Pages)

1. Push project to GitHub
2. Go to Repository Settings
3. Click "Pages"
4. Select Branch → `main`
5. Save
6. Your site will be live
